Mapping OB-GYN Care Coordination Through Medicare Shared Patient Networks

This study analyzed 60,422 OB-GYN providers and 105,891 shared-patient relationships using 2015 CMS Physician Shared Patient Patterns data to map referral networks and overlay maternal health outcomes. The analysis revealed that 80% of OB-GYN providers operate in complete network isolation — sharing zero patients with any other provider in the dataset. Five regression models confirmed that provider network structure alone does not predict county-level severe maternal morbidity (R² < 0.03). However, 54 target counties were identified where high complication rates intersect with weak provider networks — representing priority candidates for virtual care intervention.

Phase 1: Data Acquisition

This notebook downloads and organizes the raw data files used throughout the project: CMS Physician Shared Patient Patterns (2015), the NPI Registry, NUCC Taxonomy codes, CDC WONDER Natality data, and the Census Bureau ZCTA-to-county crosswalk.

Phase 2: Data Preparation

This notebook filters the CMS data to providers classified under OB-GYN taxonomy codes, cleans and standardizes fields, merges provider attributes, and produces the final edge list and provider table used in all downstream analysis.

Phase 3: Exploratory Data Analysis & Visualization

This notebook explores provider demographics, subspecialty distributions, entity types, edge weight distributions, network degree analysis, and performs the initial geographic overlay with county-level maternal morbidity rates.

Phase 4: Network Analysis

This notebook constructs the full provider network graph and OB-GYN subgraph, calculates centrality measures (degree, betweenness, eigenvector), applies Louvain community detection, classifies providers into tiers (Hub, Connected, Peripheral, Isolated), and analyzes state-level network metrics.

Phase 5: Geographic Overlay & Regression Modeling

This notebook merges network metrics with county-level maternal morbidity data, produces choropleth maps, runs five regression models (OLS, WLS, Beta Regression, Negative Binomial, GLM Gamma), performs model diagnostics, and identifies 54 target counties where high complication rates intersect with weak provider networks.
