HMO/Health Plan's Financial Statement Search

Finances affect your HMO care. This database allows you to download HMO and health plan financial information since January 2002.

The search allows you to download financial statement filings by specifying the plan name, type of HMO or health plan, statement type, and/or period ending date. If more search criteria is selected, then the search will be more refined. For example, if "Monthly" is chosen for the statement type, then ALL monthly filings received will be listed. If "Monthly" is chosen for statement type, "Dental" is chosen for Type of HMO or Health Plan, and "January 2002" is chosen for Period Ending Date, then all monthly financial statements for all dental plans with the period ending January 2002 will be listed.

NOTE: Not all HMOs or health plans are required to file monthly financial statements.

If a specific financial statement is not listed, please email Financial Reporting at HealthPlanReporting@dmhc.ca.gov.
