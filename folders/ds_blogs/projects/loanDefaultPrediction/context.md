## Dataset Summary (HMEQ)
The Home Equity dataset contains records for 5,960 home equity loan applicants. The target is **BAD** (1 = client defaulted or seriously delinquent, 0 = paid as agreed). Typical features include:
- LOAN, MORTDUE, VALUE (loan and property amounts)
- REASON, JOB (categoricals)
- YOJ, DEROG, DELINQ, CLAGE, NINQ, CLNO, DEBTINC (credit history and ratios)

Many features have missing values, so imputation and handling of missingness are important.

## Business Problem (short version)
A bank wants to automate the loan approval decision with a model that predicts which applicants are likely to default. The cost of approving a defaulter (false negative) is generally higher than rejecting a good applicant (false positive), so the model should be tuned for **recall** on class 1 while keeping precision reasonable. F1 or recall will likely be the headline metric, with AUC as a secondary check.
