Five-Step Diagnostic Process

A short routine for turning a pandas, numpy, or Python prompt into the right one-line answer. Work the five steps, then copy the template from the matching recipe card.

Step 1: Name the inputs and the output

▼

What to do: List what you are handed (a DataFrame df, an array a, a list) and what the answer should be (a DataFrame, a Series, an array, a scalar, a list, a dict). The shape of the output is the strongest signal for which recipe you need.

Worked example (mean cost per dept):

Input: df with columns patient, age, dept, visits
Output: a Series of mean cost indexed by dept
=> output is one value per group => groupby + agg

Step 2: Pick the family

▼

What to do: Decide pandas, numpy, or plain Python. Tabular data with named columns is pandas. A numeric grid or vector is numpy. A bare list, string, or dict is plain Python.

Worked example (mean cost per dept):

[x] pandas   [ ] numpy   [ ] python
The data is a labeled table, so this is pandas.

Step 3: Match the output shape to a recipe

▼

What to do: Use the Decision Tree tab. In pandas: fewer rows is filter; reordered is sort; a new column is newcol / apply / datetime / rename; one row per group is groupby; a tally is value_counts; columns from another table is merge; a wide grid is pivot. State it in one sentence: this is a __________ because __________.

Worked example (mean cost per dept):

This is a group-aggregate because I need one summary row per dept.

Step 4: Write the assignment

▼

What to do: Copy the template from the recipe card and swap in the real column and value names. Assign the answer to the variable the prompt names, usually result. Build on df.copy() if you must not mutate the input.

Worked example (mean cost per dept):

result = df.groupby('dept')['cost'].mean()

Step 5: Check the dtype and the index

▼

What to do: Most false fails are dtype and index noise: an int column promoted to float by a NaN, a leftover non-default index after filtering, a Series where a DataFrame was expected. reset_index(drop=True) and astype fix most of these.

Worked example (mean cost per dept):

result = result.reset_index()   # if a flat DataFrame is wanted
df['visits'] = df['visits'].fillna(0).astype(int)
